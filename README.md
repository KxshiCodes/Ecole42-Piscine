## 🏊 Current Focus: Swim Through the Projects

Don't worry about getting everything perfect, and don't spend too long stuck on a single project. Keep moving forward at a steady pace.

If an exercise feels too complicated, don't hesitate to skip it and come back later. Consistent progress means more practice, a better understanding of concepts and greater confidence.

You might find that the exercises you once skipped are no longer so difficult.

**The goal isn't perfection. It's progress.**

## 🎓 No Cheating. Choose Learning Instead

Here is the million-dollar question:

**How do I solve a problem when I have no idea where to start?**

The answer is simple: use references to learn, not shortcuts to avoid learning.

Looking at solutions can be a valuable part of the learning process. The important thing is not to copy code blindly, but to understand what it does and why it works.

My advice:

1. **Try first.** Write at least the basic structure yourself.
2. **Consult references.** Review solved exercises and look for similar patterns.
3. **Transcribe if necessary.** Writing code yourself helps you understand its structure.
4. **Run and experiment.** Change things, observe the results and learn from them.
5. **Debug step by step.** Use the VS Code debugger to understand how the code executes.
6. **Try again from memory.** Rewrite the code without looking at the solution, or use references when needed.

**Use references to learn, not to pretend you already know.**

## 🔄 Learning Cycle

**Understand → Implement → Experiment → Build → Reflect**

- **Understand:** Develop a clear mental model of the concept and why it works.
- **Implement:** Turn that understanding into working code.
- **Experiment:** Explore edge cases, limitations and alternative approaches.
- **Build:** Apply what I've learnt to practical problems and projects.
- **Reflect:** Record key lessons, recognise mistakes and identify areas for improvement.
